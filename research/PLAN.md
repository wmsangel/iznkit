## Очередь

**Режим исполнения** (кто дешевле по токенам владельца): **→cursor** — механика/тираж стабильного паттерна, промт дешёвый, проверка = спот-чек + сборка. **→сам** — где трудно *решить что делать*: контент (текст = продукт), SEO-судейство, завязка на нестандартный стек проекта (@react-pdf, 6-файловый паттерн), где Cursor промахнётся и диагностика сожжёт больше. **→гибрид** — подход и первый образец за мной, тираж по образцу — Cursor. Глубина проверки: →cursor — спот-чек; →сам/рискованное — полное ревью. Теги проставлены после сверки с кодом (16.10).

1. **Зафиксировать lastmod в sitemap** — 140 из 178 URL получают lastmod = время билда; каждый деплой «обновляет» все страницы, Google перестаёт доверять. Дать инструментам статичную/контентную дату (как у гайдов). `индексация` · **→сам** (SEO-решение + мелочь в 1 файле `sitemap.ts`; надо решить источник даты — в реестре поля даты нет; экономии от выноса нет)
2. **Собрать генератор УПД** — счёт-фактура (графы 1–11) + реквизиты первички в одном документе, статусы 1 (СФ + передаточный) и 2 (только передаточный); переиспользует пайплайн счёта-фактуры. Высокий RU-спрос, отдельный лендинг. `контент` · **→сам** (легальная RU-форма = контент + нестандартный PDF-стек @react-pdf с граблей hyphenation; Cursor промахнётся по форме и шрифтам)
3. **Собрать WebP-конвертер / сжатие картинок** — подтверждённый спрос (на izntools «WebP Converter» обгоняет главную); у нас есть size/base64, но конвертера нет. Client-side через FileReader + canvas, без загрузки на сервер. `контент` · **→гибрид** (UX/контент и выбор canvas-подхода за мной; 6-файловый каркас + стандартная canvas.toBlob-логика — Cursor по образцу)
4. **Расширить dev-инструменты (v2)** — chmod-калькулятор, XML formatter, minify/beautify (HTML/CSS/JS), cron-builder (отличается от существующего cron-parser), палитра/оттенки (расширение существующего `color`); по 6-файловому паттерну. `контент` · **→cursor** (тираж стабильного 6-файлового паттерна на ~4 новых инструмента; логика стандартная/библиотечная; сверено — не сделаны; спот-чек + сборка). Нужен от меня готовый промт с паттерном и списком инструментов.
5. **Добить RU-закрывающие документы** — ТОРГ-12, акт сверки, ГОСТ-QR оплаты на инвойсе, экспорт в Word/Excel. Переиспользуют PDF-пайплайн, каждый = отдельный лендинг. `контент` · **→сам** (легальные формы = контент + тот же нестандартный PDF-стек; точность важнее тиража)
6. **Дособрать инструментацию §F** — `tool_use:calculate` на остальных калькуляторах (margin/vat/discount/compound/breakeven/datediff/age/aspect/marketplace-payout/price), outbound на /projects, cta_click гайд→инструмент. Дёшево, через `useToolUsed` + `TrackedLink`. `инфра` · **→cursor** (однотипная правка: хук `useToolUsed` + `onInput={markUsed}` на ~10 калькуляторов по образцу уже сделанных 5; сверено — на этих 10 хука нет; спот-чек). Событийное соглашение уже стандартизировано — Cursor просто повторяет паттерн.
7. **Добавлять калькуляторы длинного хвоста** — стройка/быт/здоровье точечно, дёшево (модель Omni/allcalc); брать темы из GSC-спроса. `контент` · **→гибрид** (что строить — решаю я по данным спроса + формула/контент; 6-файловый каркас — Cursor)
8. **Подключить AdSense** — код готов (pub-5535516142831006); гейт — трафик. Подать, когда монитор готовности скажет «трафик дорос». `деньги` · **→сам** (мелочь + гейт по трафику/одобрению; в основном действие владельца в кабинете, размещение `<ins>` — решение по вёрстке)

## Заметки

- **Состояние:** 60 инструментов, 20 гайдов, EN+RU. Маркетплейс-кластер собран (unit-economics, payout, price, commissions, margin, таксы); NDA-кластер — топ по показам. Донат (3 сети), FAB поддержки/фидбэка, кросс-промо 14 сайтов, IndexNow-автопинг — готово.
- **Барьер №1 — трафик.** Клики из поиска ≈ 0, но показы растут (213 за 7 дней). Пока органика не вырастет, и AdSense, и аффилиаты у потолка. Мониторят adsense-readiness-monitor + утренний аналитик.
- **Заблокировано:** платежи Lava.top (нет `LAVA_API_KEY` + webhook-secret от владельца); аффилиаты 1Password/Proton (ждут одобрения программ).
- **Монетизация** — подробно в `MONETIZATION.md` + живой документ-артефакт (ссылка в памяти affiliate-audit): офферы, статусы, куда подать, политика do-follow/nofollow по сети.
- **Вектор денег §D:** прямые программы финансы/ИП (банки для ИП, бух-SaaS, аналитика маркетплейсов) — контекстно на инвойс/маркетплейс/счёт-фактура страницах, когда появятся.
- **Процесс:** одна задача = один пуш; локальный `next build` как гейт; прод-проверка cache-busted curl (память deploy-economy). После каждой задачи — обновить этот файл и переопубликовать витрину на тот же URL. Детали — память roadmap-dashboard.
- **Дневной аналитик** (утренняя рутина) автономно жмёт SEO quick-wins (мета для позиций 5–15), пингует IndexNow, 1 URL/день в GSC, пишет идеи в `IDEAS.md` — контент не строит.
- **Разобрано, не меняем:** canonical главной (`/` вместо `/en` — косметика Google для корня, не баг).
- **Припарковано (не в очереди):** переезд на Cloudflare Pages/Workers — ⛔ гейт: ~15 PDF-роутов на @react-pdf (Node-runtime), нужен пилот «едет/не едет» (IDEAS §I); UX-избранное/пиннинг + PWA «на домашний экран» — после роста трафика (удержание важно post-traffic); новый аффилиат-вектор финансы/ИП — ждёт прямых программ; NDA-пресет «для питча игры издателю» — ниша, по запросу.
